# Practical 16: Multi-Container Application

## Aim
To create a multi-container application using Docker Compose.

## Requirements 
- Docker Desktop
- Docker Compose

## Procedure
1. Open the project folder in the terminal.
2. Run the containers using:

   docker compose up -d

3. Check containers:

   docker compose ps

4. Open the web servers:
   - Nginx: http://localhost:8080
   - Apache: http://localhost:8081

5. Stop the containers:

   docker compose down

## Conclusion
Successfully created and tested a multi-container
application using Docker Compose.
